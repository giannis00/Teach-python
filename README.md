# Python teaching materials

Lesson notebooks, worksheets and small projects for teaching Python to beginners, from the first `print` to classes, linked lists and Big O notation.

**Instructor:** Ioannis Tsioulis

The notebooks open in Google Colab with one click, so there is nothing to install. The worksheets are PDF or text files; where answers exist, they are linked in the last column.

> **Looking for a complete course?** This material was rewritten, with full explanations, as [*From Zero to Data Structures and Algorithms in Python*](https://giannis00.github.io/teaching/#data-structures) on my website.
